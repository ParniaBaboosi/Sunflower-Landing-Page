# 🌻 Sunflower Landing Page

A simple and beautiful sunflower-themed landing page built with HTML and CSS.

## ✨ About the Project

This project is a simple landing page inspired by the beauty of sunflowers. It was created as a practice project to learn the fundamentals of web development and improve my HTML and CSS skills.

## 🛠️ Technologies Used

* HTML5
* CSS3
* Flexbox
* Font Awesome
* Google Fonts

## 🎨 Features

* Dark-themed design
* Sunflower-inspired content
* Profile image
* Social media icons
* Hover effects
* Styled button
* Responsive layout

## 📂 Project Structure

```text
Sunflower-Landing-Page/
├── index.html
├── style.css
├── images.jpg
└── README.md
```

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## 📚 What I Learned

* Creating web pages with HTML
* Styling elements with CSS
* Using Flexbox for layout
* Adding images and social media icons
* Creating hover effects
* Working with colors, fonts, and spacing
